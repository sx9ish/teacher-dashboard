# Teacher Dashboard

Интерактивная веб-панель для мониторинга успеваемости учебной группы по курсу веб-разработки в колледже. Проект выполнен в формате учебного пет-проекта.

Приложение позволяет преподавателю отслеживать прогресс студентов, автоматически рассчитывать средний балл и вовремя замечать должников.

## Основные функции

* Панель ключевых показателей (средний балл, процент сданных работ, количество должников).
* График сдачи лабораторных работ по темам курса.
* Таблица студентов с поиском, прогресс-баром и цветовой подсветкой зоны риска.

## Технологии

* HTML5, CSS3, JavaScript
* Библиотека Chart.js (для графиков)
